# 工具 线路与复用目录

- [tools.json](tools.json)：国内个人工具入口、使用环节、能力与限制、官方来源。
- [routes.json](routes.json)：motion_comic、story_video、agent_first 三条输入输出与人工检查路线。
- [reuse.json](reuse.json)：第三方源码固定提交、许可证与复用边界。

资料核对日期记录在文件内。这里没有实时价格，也没有声称完成账号内功能测试、模型接入或源码 fork。

本地 creator 命令只读取这些目录。新增工具时同步核对官方归属、来源日期、账户准入和许可证；先修复引用再更新线路。可读版本见[工具指南](../docs/creator-guide/06-tools.md)与[复用指南](../docs/creator-guide/07-reuse-and-fork.md)。
