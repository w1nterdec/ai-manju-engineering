# 个人实际制作待办

当前先选择一条[个人生成线路](creator-guide/02-workflow.md)，准备原剧本、角色参考和姓名读音，制作一条 30—60 秒小样。使用网站生成、试听、筛片及发布由本人确认；不需要先开 API、部署平台或完成下列历史工程清单。

实际制作后保存：原文、参考版本、提示词、全部候选、失败原因、实际费用和最终审片结论。源码 fork 属于可选后续动作，先按[复用指南](creator-guide/07-reuse-and-fork.md)核对需要。

# 仅人工可完成的事项

- PR #1 合并：用户已在 2026-10-24 明确授权代理检查通过后合并，本项不再阻塞本轮。后续 PR 仍按届时用户授权处理。
- 真实服务与成片评测：需要使用者自行选择供应商、在自己的环境配置密钥和预算，并实际生成、试听、观看；开发代理不会索要或使用真实密钥，不处理则只有 mock 演示证据。
- 素材、声音与肖像授权：需要权利人凭证、范围、期限与授权审核；缺失则生产交付门禁阻断，mock 记录不能替代授权。
- 地区和平台规则：需要投放负责人按最新要求核实 AI 标识和交付规范并填写配置；本项目仅检查字段与记录，不提供法律判断。
- 商业验收：客户须确认报价参数、修改轮次和实际成片；模板与自动报告不等于客户验收。
- 真实效果和目标软件验收：实际名字读音、画面与剪辑软件导入需使用者试听观看确认。ffprobe 安装、免费合成技术样本、四项代码边界修复与回归测试并非人工独占任务，可按成长路线离线推进；特定剪辑工程格式仍无兼容承诺。
