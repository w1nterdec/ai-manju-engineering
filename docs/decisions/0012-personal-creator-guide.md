# 0012 回归个人创作者指南与生成线路

日期：2026-10-25。状态：采用。依据：用户明确要求全面修改重构项目，指出本意是解决生成问题并建立以后可参考的指南，允许研究复用或 fork 现有平台。

## 决定

主入口服务中国大陆个人 AI 短剧与漫剧作者。以姓名读音、画面质量与一致性、剧情分镜匹配为主线，提供真实工具地址、分步操作、提示词、生成线路、样例和最小返工。本地自动化只承担可复现的资料整理和引用检查，真实生成在使用者选择的平台执行。

优先使用现有产品；开源工作台可独立评估。使用网站、调用 API、fork 源码必须分别确认，不因网站可访问就假定可复制，不因开通会员就假定有 API 权限。

## 对既有方向的影响

本决定替代 0001、0011 中的业务画像扩张和平台成长优先级，以及此前工业平台计划的当前执行地位。旧 CLI、文件契约和历史审查保留兼容；工程功能不再是学习创作的前置条件。0009 的“不为看板替代真实验证”的理由仍成立；本次静态制作包只是离线交接资料，不是新增生产 Web 服务。

0.9.0 是本次指南重构版本，不能解读为旧候选 0.9 的本地实媒生产链已经实现。四项历史 P2 在旧工程模块中仍按原审查记录，不以此次改入口宣称已修复。

## 授权与验证

本次授权覆盖仓库代码、文档、结构和示例的重构。引用第三方项目而未创建远端 fork；没有采购、真实生成、使用密钥或自动发布。指南、目录、原文检查和资料导出由离线测试验证，效果与实际费用仍要在真实创作时记录。
