# 0007：通用交接与独立校验

选择 JSON/CSV（毫秒时间码）/SRT 通用交接，不承诺某剪辑软件直接导入工程。具体软件的交换格式没有在本环境实测，列入人工待办。

生产包要求真实审核媒体、授权摘要、非 mock 实测时间轴、最终视频、实际 provider/model/参数/提示词来源、经使用者核实的 AI 标识。外部手工制作可以提交 provenance 1.0，不需要工具接触生成密钥；记录实际提示词及摘要，同时关联批准镜头说明。记录由使用者负责真实性。

demo 明确拒绝作为客户成片，允许 mock 运行且不冒充人审。成本默认不附，显式 include-costs 才加入。包在临时目录完成后发布，逐文件 SHA-256 索引，独立验证器检查修改、缺失、额外文件和越界。

回滚：保留旧交付目录，重建新版本，不覆盖。影响：完整性摘要不提供数字签名，不能证明权利法律效力或内容质量。不确定度：中；复核触发：真实客户交付、剪辑软件导入验证或可信签名需求。
