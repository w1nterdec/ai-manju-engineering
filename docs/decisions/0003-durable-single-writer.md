# 0003：SQLite 日志与单写入执行器

背景：本地小团队需要跨平台中断恢复，且核心零依赖。备选：JSON 散文件、标准库 SQLite、外部队列。选择 SQLite 事务保存状态和追加事件，原子导出 JSON。

OS 文件锁限制每个运行目录只有一个执行器，进程退出自动释放；主线程写事务，受控线程运行 provider。并发、尝试次数和退避有上限。取消停止新调度，在途任务完成后保存。

幂等键按实际任务参数、路由及依赖键计算，局部变化只使相关下游 stale。成功产物复用前检查摘要。mock 崩溃可用同一幂等产物恢复；未来真实任务必须先核对供应商任务，不能盲目重提扣费。

人工节点默认 needs_review。auto-review-mock 只表示模拟审核，不是实际人审，不可用于生产交付。

回滚：旧 build/gate 保持可用，保留运行库审计。影响：不支持多机共享 SQLite。不确定度：中；复核触发：首个真实任务或多机并发。
