# 0010：以包含边界修复的验证快照建立收尾标签

M0–M4 按各自通过验证的历史提交保留标签。M5–M7 功能完成后，最终复核补充了离线协议限制、截断媒体检测、声音授权分类和打包期间变更检查，因此 M5–M8 标签共同绑定最终验证快照，避免把已知需要修复的中间版本当作推荐回滚点。各阶段原始版本、提交与变更记录仍完整保留，不改写任何历史。

STATE 记录最近一次已核验的功能推送与时间，最终提交本身的 SHA 由 git log、远端引用与标签提供。提交内容无法包含它自己的最终摘要，不能伪造这种自引用记录。

推送前扫描包括工作树、暂存区、全部待推提交的新增行与历史大对象。扫描只是检测机制，不提供零遗漏证明；本次没有读取或使用任何生成服务密钥。

回滚：选择对应已验证标签，在新分支追加修复；禁止强推、移动已推标签或自行合并。复核触发：新的安全边界问题或真实生产验证出现。
