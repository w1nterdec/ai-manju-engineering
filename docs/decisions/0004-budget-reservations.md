# 0004：先预留预算、再派发任务

背景：并发任务只在完成后记账会穿透预算。选择 Decimal 和共享 SQLite BEGIN IMMEDIATE，在调用前原子预留最坏回退费用，完成后追加 release/actual，崩溃未结算的预留继续占用。

预算分项目、集、镜头、批次。默认共享账本在运行目录父级 .manju/costs.sqlite3，可通过 budget_account 显式配置，同一项目跨集与运行共用预算。积分来源分开保留，用版本化显式换算转换到内部币种；无换算即拒绝，不写真实厂商价格。

mock 失败尝试默认模拟计费，重试纳入实际模拟台账；幂等预留与结算防止恢复时重复记账。最低估算使用首路由一次，上界包含全部回退与最大尝试。报价受配置质量影响，不是供应商承诺。

回滚：停用执行，旧计划与 gate 保持兼容，保留账本审计。真实服务接入前必须补充对账和未知账单处理，不能把未知成本视为免费。不确定度：中；复核触发：真实积分、汇率、税费或供应商超时账单接入。
