# 0008：画像作为可校验配置

按用户给定顺序实现 series_drama、ad_batch、client_service、shoppable_export。画像定义交付项、必检项、分母指标、人工成本开关与表单模板；核心算法按配置执行，不按画像名散落分支。

广告批次是明确的独立命令：只转述用户商品输入，不补写功效或承诺；变体记录父摘要、SKU、hook 和商品参考 ID，批次共享预算，单项失败隔离。生产交付要求画像检查与最终文件绑定，特有交付文件缺失会阻断。

接单报价只计算用户参数，利润率与加价率明确区分；可购物只导出元数据。无真实市场或收入数据进入代码。回滚：旧命令和项目契约保持；删除新模板不影响已冻结构建。不确定度：中；复核触发：真实客户画像、商品投放要求或批次规模测试。
