# 0005：素材批准与授权记录分离

背景：内容一致不意味着授权充分。选择以内容摘要存 blob，以完整来源/授权/批准记录摘要作为不可变资产版本。批准产生新 ID 并保留 parent_id；剧本外的身份配置引用实际批准版本。

计划默认警告未批准身份，可配置 block。生产 gate 无条件检查所需范围、期限、限制说明、凭据文件及批准，并拒绝 mock。人工批准只表示记录，不提供法律结论；以所在地区与平台最新要求为准，由使用者核实。

血缘绑定构建摘要、任务输入、模型、参数、依赖和结果，禁止给不匹配的构建附上旧运行来源。授权原件保留在本地资产库，公开仓库不保存客户凭据。

回滚：保留记录和 blob，恢复旧批准资产引用。影响：凭据完整性不能证明其法律效力；审核人身份无签名认证。不确定度：中；复核触发：真实合同、地域或平台要求出现。
