# 完成第一条样片

目标：用现有工具完成一条能讲清故事、名字读对、角色可辨、文件能找回的 30—60 秒样片。建议先做 5—8 个镜头、2 个角色、1 个场景。这个规模是起步建议，不是对成片质量、时间或费用的承诺。

## 先选一条线路

- 以旁白和静态图为主：选 `motion_comic`，先用即梦与剪映。
- 需要人物动作与表演：选 `story_video`，主视频工具只选一个。
- 想让平台先组织故事板：选 `agent_first`，按小云雀的 [官方手册](https://xyq.jianying.com/tutorials/web-manual)操作。

线路详解和入口见 [工作流](02-workflow.md)。

## 第一步 写一张制作卡

复制以下内容，放在自己的项目笔记中。先填写已有答案；没决定的项目写“待确认”。

```text
片名：
这条片讲给谁看：
一句话故事：谁想要什么，遇到什么阻碍，最后发生什么变化
采用线路：motion_comic / story_video / agent_first
画风与画幅：
角色与固定服装：
必须被观众知道的三个事实：
本次绝不改动的台词：
姓名与术语的确认读音：
主要工具与备用工具：
本次允许的费用与重试上限：
```

可以向豆包或 DeepSeek 复制 [项目简报提示词](../../prompts/01-project-brief.md)，帮助整理。不要把 AI 补写的设定直接当作自己已确认的内容。

## 第二步 锁定角色与声音

为每个主要角色先做一张清楚的头像与一张全身图，必要时增加侧面。确认是同一个人、同一套服装，并保存选用版本。

给配音工具输入几句小样：完整姓名、别人喊他的名字、名字放在句子中间、带情绪的称呼。实际听到正确后再批量配音。读音注释不要直接混进朗读正文；具体控制方式按音色与工具支持设置。

**产物：**角色参考图、声音选择、姓名读音表。不会录音或暂时不选 TTS 时，可以先自己录临时配音，用于试节奏。

## 第三步 拆成能制作的镜头

先写每个镜头必须让观众知道什么，再写画面。不要先追求复杂运镜。

```text
镜头：S001
要传达的事实：
画面中的角色与位置：
景别：
一个主要动作：
对应原台词或旁白：
临时配音长度：
需要沿用的参考图与服装版本：
最容易出错的细节：
```

用 [剧本转分镜提示词](../../prompts/03-script-to-shots.md)生成草稿后，自己逐句核对。数据契约和 JSON 是可选工程输出，手工创作可以先用文字或表格。

## 第四步 只完成第一个代表镜头

选择包含本片主要角色、风格和道具的镜头；不要只用无人空镜证明流程成功。

1. 先做静态关键图，检查脸、衣服、人物位置与关键道具。
2. 动态漫直接进剪映试推拉与配音；剧情视频用该图生成一个主动作。
3. 整段播放，检查中间帧，不能只看封面。
4. 与原台词一起观看，确认画面真的表达了目标事实。
5. 若失败，记录原因，按 [局部返工](03-quality-and-repair.md)修改。

**通过条件：**角色可辨，读音正确，动作无明显破坏，剧情信息没有表达反。通过后再制作其他镜头。

## 第五步 剪出全片

把选用镜头、实际配音、音效和字幕放入 [剪映](https://www.jianying.com/)。先完成粗剪，再处理美化。对白超长时调整镜头或台词，不靠不自然加速硬塞。

字幕从最终批准的原文校对，重点看姓名、多音字、数字和否定词。画面出现重要文字时，优先保留可编辑的后期文字层。

## 第六步 做一次完整验收

- [ ] 关掉其他窗口，从头到尾完整播放。
- [ ] 对照原文，确认没有漏句、串说话人或改变关键事实。
- [ ] 逐次听清姓名与术语，不以自动转写正确代替读音验收。
- [ ] 核对角色、服装、道具、人物方位与声音。
- [ ] 保存最终文件、剪辑工程、选用素材和返工记录。
- [ ] 发布前阅读 [发布准备](05-publishing.md)。

如果没有完成真实生成和观看，只能记录“准备完成”或“待验收”，不能把工具占位结果写成已完成作品。

## 第一条片完成后再决定买什么

统计这次实际采用镜头、所有尝试、费用和自己花的时间。先判断瓶颈是写故事、拆镜、角色控制、配音还是剪辑，再增加工具或自动化。工具表见 [指南入口](README.md)，文件组织见 [制作记录](04-production-records.md)。
