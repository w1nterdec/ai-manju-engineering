# 国内工具怎么选

核对日期：2026-10-25。这里整理的是中国大陆个人创作者可参考的官方入口、公开能力和交接方式，没有登录试用、付费生成或效果排名。价格、账户权益和模型上限变化较快，开始制作前再看实际产品页。

先选一条[生成线路](02-workflow.md)，再选工具。一个主生成工具加一个后期工具就可以开始，不必把清单全部订阅。

## 按你的作品选最小组合

- **图片动态漫 `motion_comic`**：豆包或 DeepSeek 整理剧本，使用即梦准备角色、场景和分镜图，在剪映用推拉、移动、蒙版、配音和字幕组织故事。确实需要表演的少量镜头再生成视频。
- **逐镜剧情短片 `story_video`**：先批准参考图，再从即梦、可灵、Vidu、海螺中选择一个主工具，按镜头生成候选片；配音可用讯飞或自己录制，剪映终剪。需要备用时再试第二个视频工具。
- **一站式试做 `agent_first`**：在小云雀确认剧本、角色、场景和故事板，逐段检查与重拍，再导出并在剪映完成最终检查。平台自动化仍需要你确认内容。

如果已有适合的开源工作台，可以先复用它的画布和素材管理；是否 fork，见[复用与 fork](07-reuse-and-fork.md)。

## 剧本与分镜草稿

**[豆包](https://www.doubao.com/)**适合讨论故事、人物关系和台词；**[DeepSeek](https://www.deepseek.com/)**可用于整理分集结构、镜头描述及检查遗漏。让它们输出待确认的草稿，保存原剧本与角色设定，逐项检查事实和台词。

这里推荐的是个人对话入口。本项目不会自动登录这些网站；网页会员、个人对话额度和 API 账户要分开核对。DeepSeek 官网分别提供[对话](https://chat.deepseek.com/)与[API 开放平台](https://platform.deepseek.com/)入口。

## 图片与视频制作

**[即梦](https://jimeng.jianying.com/)**：可用于角色、场景、关键图和逐镜视频。开始前固定角色图与主要描述；每次生成后检查人物、视线和动作。[官方短剧指南](https://jimeng.jianying.com/tools/ai-short-drama)介绍的是分镜、逐镜制作和后期组织，不应理解成整部剧一次生成即可交付。

**[可灵中文入口](https://klingai.kuaishou.com/)**：可作为图生视频与多参考路线候选。[快手官方公告](https://ir.kuaishou.com/zh-hans/news-releases/news-release-details/kuaishoukelingaituichuduotucankaogongneng/)介绍了人物、服装、物品与场景组合参考。公告发布于 2025 年，不能用其中的模型名和参数代表当前账户；参考控制也不保证每个镜头都正确。

**[Vidu 中国站](https://www.vidu.cn/)**：官网提供参考生图、参考生视频、图生视频及 Agent 等入口，并区分个人与企业套餐。按所选模型确认参考方式、时长和音频条件。[API 常见问题](https://platform.vidu.cn/docs/overview/faq)是另一套接入和充值流程，个人起步不需要先开发 API。

**[海螺国内创作入口](https://hailuoai.com/video/create)**：可作为视频和主体参考试拍候选。[MiniMax 官方发布说明](https://minimax.cn/news/s2v-01%E5%8F%91%E5%B8%83)明确区分国内入口与海外 `hailuoai.video`。该说明是 2025 年能力路线材料，最新规格、消耗和效果以当前模型与实际样片为准。

选择视频工具时，用同一组典型镜头比较：人物近景、双人关系、手持道具、行走动作、简单运镜。记录每个镜头的全部尝试、选用结果及费用，再决定主工具。不要只比较官网样片或单次成功截图。

## 一站式创作

**[小云雀](https://xyq.jianying.com/)**的[官方 Web 手册](https://xyq.jianying.com/tutorials/web-manual)给出上传剧本、确认需求、全局角色、全局场景、故事板编辑、合成导出的流程，并包含角色不一致处理和片段重拍。适合先把一场戏跑通，再判断是否符合自己的画风、叙事与返工方式。

小云雀个人产品、即梦个人产品和火山剧创企业服务的能力与准入并不相同。不要因为一个平台有某项功能，就假定所有同厂商账户和 API 都已经开放。本项目只提供操作参考与制作包，没有接入平台内部 Agent。

## 配音与后期

**[讯飞智作及讯飞配音](https://peiyin.xunfei.cn/)**：可用个人网页操作逐句试听、停顿和读音设置。[官方帮助](https://peiyin.xunfei.cn/about)说明多音字和数字读法等控制。先检查姓名读音，再固定音色并批量制作；纠音文本与字幕原文分开保存。[服务协议](https://peiyin.xunfei.cn/youshengStatic/protocol/zhiZuoUserAgreement.html)与具体音色授权应在购买前核对。

**[剪映](https://www.jianying.com/)**：作为基础后期中心，完成镜头剪辑、关键帧、蒙版、文本朗读、音频处理及导出。先把真实配音放进时间线，再核对对白与画面时长。音乐、字体、模板和声音按[素材许可协议](https://sf1-cdn-tos.douyinstatic.com/obj/ies-hotsoon-draft/vco/f72e9cd9-cc19-4db7-ba74-0794833ce854.html)分别确认，会员不代表所有素材均可全平台商用。

## 有技术需要后再用的工具

**[LiblibAI 工作流入口](https://www.liblib.art/workflows)**提供模型与工作流创作入口。具体模型、社区节点、工作流消耗和许可各自核对。本轮公开页面部分依赖脚本，没有实际运行其工作流。

**[ComfyUI](https://github.com/Comfy-Org/ComfyUI)**可用于可重复的本地图像、视频和音频节点流程。它需要匹配的模型与计算环境，软件许可不包含免费 GPU 或模型服务；软件、权重、LoRA、节点许可分别检查。先复用经过自己验证的固定工作流，不需要为了第一条短片搭建大量自定义节点。

**[Toonflow](https://github.com/HBAI-Ltd/Toonflow-app)**可优先评估为自己的创作工作台：用画布组织文本、角色场景及图片视频素材，自行配置模型。它与本指南的关系是可选工作台；本仓库没有替你部署，也没有把其源代码复制进来。固定版本的 MIT 许可与复用步骤见[下一篇](07-reuse-and-fork.md)。

## 开始生产前记录什么

为本次实际使用的工具保存：官方地址、产品与模型名称、日期、输入参考、所用权益、输出文件和费用。未知金额记为待核账，平台赠送积分与实际付费分开。常用入口与核对来源另存于[机器可读目录](../../catalog/tools.json)，适合让自己的脚本生成制作说明和交接清单。

当网站提示需要登录或某个功能未开放时，先用手工导出导入路线继续。不要把本指南中列出的工具名当成已经实现的自动调用接口。
