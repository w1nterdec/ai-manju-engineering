# 质量检查与局部返工

把每个问题定位到最早的错误输入，只重做受影响的部分。参考图、长提示词、固定 seed 和自动评分都不能替代完整观看、试听和剧情核对。

## 一 姓名读错或声音变了

**先问：**姓名读音是否由自己确认？工具与当前音色支持什么纠音方式？这句话实际送去合成的是什么文本？角色是否用了另一音色？

操作顺序：

1. 保留出错句的原文、实际合成输入、声音选择和错误音频。
2. 用完整姓名、句中姓名和情绪称呼分别做小样，只改变必要的读音控制。
3. 使用工具明确支持的设置；[讯飞帮助](https://peiyin.xunfei.cn/about)提供多音字与停顿说明。不要把一种工具的拼音或 SSML 语法直接复制到另一工具。
4. 重新试听整句和前后连接，确认名字、语气和音量。
5. 更新该句相关字幕时间、混音和必要口型。字幕保留正确汉字，纠音替换文本只用于声音输入。

**可以继续：**本句每次姓名出现都听清且正确，角色音色一致。自动转写出正确汉字，只能辅助核对文字，不能证明字音正确。更详细说明见 [读音方案](../pronunciation.md)。

## 二 换脸 换衣 道具漂移

**先问：**是否沿用了同一参考与服装版本？参考图是否上传成功？本镜头是否引入太多角色、遮挡或动作？

先修关键图，再修视频。比较脸型、发型、衣领、配饰和关键道具，不只看“整体像不像”。身份与服装固定描述和本镜头动作分别保存。

单人简单镜头通过后再增加双人互动。模型切换、换场景或换参考后重新验收。局部编辑只在工具实际支持且能检查时采用，不能承诺所有视频都能只改一小块。

**重做范围：**依赖错误参考版本的关键图及视频，以及这些结果的审核和剪辑引用；不把无关场景自动全部推倒。

## 三 肢体瑕疵与动作错误

从失败动作里挑一个核心信息，尝试拆成动作、物件特写和反应镜头。画外音、背影或动作结果镜头可以表达剧情，但需在分镜中明确设计。

整段播放，并检查动作关键点。首帧、尾帧正确不保证中间没有多手、穿模、脸部突变或物件消失。不要用只展示成功封面的方式结束检查。

**重试规则：**先记录失败原因和本次只改什么；到达自己设定的次数或费用上限后暂停，改拆镜、后期或工具，而不是无限抽卡。

## 四 剧情和分镜对不上

回到批准原文，为每个镜头写一句“观众必须知道什么”。分别核对：

- 台词是否逐字保留，是否漏掉否定词或关键信息。
- 说话人是否正确，人物是否提前知道尚未发生的事。
- 动作是否足以表达因果；漂亮画面不能代替剧情事实。
- 人物、服装、道具归属和方位能否接上前镜。
- 关键文字是否真实可读；信件、手机、钟面等可用后期素材合成。

如果生成结果启发了新剧情，先修改并重新确认剧本版本，再改分镜；不要悄悄把偏离原文的结果当作正确。

## 五 最小返工的选择

| 发现的问题 | 优先处理 | 重新检查 |
| --- | --- | --- |
| 一句姓名读错 | 重做该句配音 | 邻句、字幕时序、混音及必要口型 |
| 角色服装版本错 | 修参考或关键图 | 引用该版本的后续镜头 |
| 视频中途多手 | 拆动作或重做镜头 | 全段运动及相邻剪辑 |
| 台词遗漏或事实反了 | 回原文与分镜 | 相关镜头及后续剧情依赖 |
| 音乐盖住对白 | 调混音 | 连接处与整片响度 |
| 重要文字生成错误 | 后期可编辑叠字 | 字形、遮挡、透视和时长 |

```text
姓名与声音：通过 / 待改 / 无法检查
角色与服装道具：通过 / 待改 / 无法检查
肢体与动作：通过 / 待改 / 无法检查
剧情事实与台词：通过 / 待改 / 无法检查
字幕与时长：通过 / 待改 / 无法检查
问题镜头与时间点：
本轮只修改：
修改后需重查：
```

没有访问实际媒体时，AI 必须写“无法检查”，不能伪造观影或试听结论。可复制 [质量审核提示词](../../prompts/05-quality-review.md)和 [局部返工提示词](../../prompts/06-local-repair.md)。制作记录见 [下一页](04-production-records.md)。
