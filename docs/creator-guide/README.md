# 中国大陆个人 AI 短剧与漫剧创作指南

这个指南用于实际创作时查步骤、选工具、复制提示词和定位返工。先用现有创作平台完成作品，再用本项目整理自己的生成线路和制作记录。无需先学 Python、JSON 或自行搭建生成服务。

资料核对日期：2026-10-25。工具网址是官方产品或帮助入口；具体模型、套餐、排队和账户权限以实际页面为准。这里没有把网页会员等同 API 额度，也没有把宣传效果当作已完成的实测。

## 从哪里开始

- 第一次制作：读 [完成第一条样片](01-first-film.md)。目标是一条 30—60 秒、5—8 镜头的小样，不先做整季。
- 已有剧本，想选生成线路：读 [工作流与三条生成线路](02-workflow.md)。
- 名字读错、画面出错或剧情对不上：查 [质量检查与局部返工](03-quality-and-repair.md)。
- 素材越来越乱：用 [制作记录与文件组织](04-production-records.md)。
- 准备公开发布：查 [中国大陆发布准备](05-publishing.md)。
- 需要查官网、能力与使用限制：读 [工具网站目录](06-tools.md)。
- 想复用或 fork 创作平台：读 [现有项目与许可证](07-reuse-and-fork.md)。
- 想复制指令：打开 [提示词库](../../prompts/README.md)，把自己的原文和参考材料填进去。
- 想使用本项目的本地自动化：按 [本地自动化与制作包](08-automation.md)创建、检查和导出，再参照 [根目录入口](../../README.md)。

## 三条生成线路

### motion_comic 图片动态漫

**适合：**旁白驱动、解说漫、少量对白，愿意用剪辑组织静态图片的个人作者。

**线路：**豆包或 DeepSeek 整理剧本 → 即梦制作角色与分镜图 → 试听配音 → 剪映关键帧、推拉、局部效果与字幕 → 完整审片。

第一条片不要求购买视频生成服务。需要动作的少数镜头再单独尝试图生视频。

### story_video 参考图到剧情视频

**适合：**需要人物动作、表情、对白和镜头衔接的动漫或仿真人短片。

**线路：**剧本和角色设定 → 经确认的分镜关键图 → 即梦、可灵、Vidu 或海螺中的一个主工具生成镜头 → 候选筛选 → 配音及剪映终剪。

先用同一组镜头比较工具，固定一个主工具和一个备用工具；不要按品牌数量配置整套订阅。

### agent_first 一站式 Agent 起稿

**适合：**希望减少手工搬运，让平台先完成剧本解析、角色场景及故事板组织，再自己审核的个人作者。

**线路：**小云雀导入剧本 → 确认需求 → 全局角色和场景 → 故事板与片段生成 → 重拍问题片段 → 合成导出 → 必要时进剪映精剪。

一站式流程同样要检查台词、角色、动作和成片。不能把平台显示“生成完成”当作自己的质量验收。

## 核验过的工具入口

- [豆包](https://www.doubao.com/)：剧本讨论、设定整理和分镜草稿。
- [DeepSeek](https://www.deepseek.com/)：文本梳理与可执行脚本草稿；网页对话与 API 平台分开。
- [即梦](https://jimeng.jianying.com/)：[官方短剧指南](https://jimeng.jianying.com/tools/ai-short-drama)介绍参考、逐镜生成、筛片与后期。
- [可灵中文入口](https://klingai.kuaishou.com/)：[快手官方多图参考说明](https://ir.kuaishou.com/zh-hans/news-releases/news-release-details/kuaishoukelingaituichuduotucankaogongneng/)可用于确认参考控制路线，不代表所有镜头必定一致。
- [Vidu 中国站](https://www.vidu.cn/)：参考生图、参考生视频、图生视频与 Agent；以所选功能及账户权益为准。
- [海螺国内视频入口](https://hailuoai.com/video/create)：[MiniMax 官方说明](https://minimax.cn/news/s2v-01%E5%8F%91%E5%B8%83)区分国内和海外入口。
- [小云雀](https://xyq.jianying.com/)：[Web 官方手册](https://xyq.jianying.com/tutorials/web-manual)列有短剧与漫剧 Agent 的六步流程和返工方法。
- [讯飞智作](https://peiyin.xunfei.cn/)：[使用帮助](https://peiyin.xunfei.cn/about)说明试听、停顿和读音控制。
- [剪映](https://www.jianying.com/)：终剪、关键帧、音轨、字幕及导出。
- [LiblibAI](https://www.liblib.art/)：需要更深控制时再研究工作流和模型许可，不是第一条片的前置条件。

## 这个项目如何帮助你

本项目组织方法、提示词、工具引用、生成线路和本地记录。外部平台负责实际图像、视频与声音生产；是否接入 API、复用开源平台或 fork，需要分别核对接口和许可证。能访问商业网站不表示能复制它的源码。

旧版离线 CLI、数据契约与审核工具可作为进阶选项：[工程架构](../architecture.md)、[数据契约](../data-contract.md)。这些不是开始创作的必读内容，也不等于真实生成服务已经接通。
