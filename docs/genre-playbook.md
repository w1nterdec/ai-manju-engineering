# 泛化到不同题材

底层稳定对象保持一致：人物、别名与读音、世界规则、剧情事实、台词、镜头、状态和媒体版本。题材改变约束与验收重点，不能靠替换风格词完成。

## 悬疑 / 推理

追踪人物已知信息、线索出现时点、证据来源和观众能看见的内容。关键证据文字用后期合成。每条推论必须有先前线索支撑，避免模型提前揭晓谜底。示例《午夜来信》展示道具、时间线索与画外音，尚未覆盖完整推理长篇。

## 日常 / 情感 / 都市

追踪关系阶段、称呼、表情强度、视线、空间距离和台词潜台词。名字读对后，还要检查情绪是否符合前一场的发展。普通交流不要靠夸张表演替代细腻反应。可用低动作双人对话作为初学者第二个练习。

## 玄幻 / 动作 / 战斗

先建立力量规则、武器、伤势、左右手、人物方位和招式阶段。把接近、碰撞、反应拆成可审核镜头，优先保证空间因果。高粒子特效容易掩盖身份和肢体问题；应保留无特效版本检查主要动作。角色变身需登记新外观版本，不能被普通换脸错误混淆。

## 喜剧 / 反转 / 轻松短剧

追踪铺垫、误解、揭示、停顿和反应镜头。笑点依赖的道具或信息必须提前出现；配音速度和停顿按实际效果调整，不机械套用统一字数。检查音效是否破坏对白可懂度。

## 科幻 / 历史 / 世界观题材

建立专有名词词典、技术或制度规则、时空与服装设定，区分真实背景事实和虚构设定。需要真实性的内容先查证，模型不能自行补写成既定事实。长篇把设定变更放入版本审查，防止不同集出现互相矛盾的世界规则。

## 可替换的项目参数

画幅 9:16 适合本示例，不是仓库的固定要求；横版、方形和其他画幅由 `aspect_ratio` 表达，真实模型支持范围由适配器检查。视觉风格与题材分开：悬疑可用漫画、3D 或写实，动作也可用有限动画。

下一阶段应为每个题材至少制作一条完整真实样本，再决定哪些提示词可以共用，哪些需要专用模块。目前只有原创悬疑计划样例，不能据此宣称多题材效果已经验证。
