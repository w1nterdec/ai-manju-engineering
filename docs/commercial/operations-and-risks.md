# 小团队作业、交接与风险登记

## 标准作业

1. 选择画像并填写简报、原剧本、身份资产、读音和商品资料；确认委托人与素材范围。
2. 冻结构建，验证共享设定和镜头状态，生成成本预览，填写四级预算。
3. 离线 mock 跑通流程；真实工具由使用者在自身授权环境操作，保存实际模型、请求、结果与费用。
4. 审核参考图、身份、声音、逐镜头与实测字幕；返工只影响实际依赖，更新版本与审核记录。
5. 核对授权、平台规格、AI 标识和画像特有检查。客户交付前检查最终成片，导出包并独立校验。
6. 保存交付摘要和验收单；修改轮次追加记录。客户接受前状态仍为待验收。

## 交接清单

成片摘要、字幕与时间轴、原剧本/镜头来源、实际生成记录、素材授权摘要、质量报告、AI 标识记录、画像特有文件、修改与客户验收记录。报价/成本默认不向客户报告，显式选择才附。

## 风险登记

- 版权、肖像、声音：凭据与使用范围可能不适用于当前用途，需权利审核人复核；缺记录阻断生产包，记录完整也不是法律结论。
- 平台规则与 AI 标识：可能变化，需记录来源、日期和核实人，以地区及投放平台最新要求为准；工具不自动发布或断言合规。
- 模型停服与供应商依赖：保留实际参数、输入和来源；路由支持替换，但替换后质量和成本须重新验证。
- 积分/汇率/重试：换算不代表实际到账价，未知费用应保留不确定性；超时查询与真实账单核对需在真实适配器接入时补齐。
- 质量与授权责任：自动技术检查不等于叙事、读音、商品真实性或客户验收，按确切媒体版本人工确认。
- 数据与交付：授权原件和客户数据不入公开仓库，交付包权限与保留周期由使用者管理；文件摘要不是数字签名。

## 演进路径（仅讨论）

获得实际小团队交付样本后，再评估只读视图、协作或服务化成本。当前不实现 API 转售、多租户 SaaS、订阅计费、平台账号自动发布或直播带货，也不对这些模式提供收入预测。
