# 评测与“对标顶尖”的证据要求

> 本页属于可选工程参考。个人实际制作先读[创作指南](creator-guide/README.md)；原有 mock 或接口契约不表示真实平台已接通。

## 分开评估三类能力

1. **工程正确性**：畸形输入、重复 ID、漏句、状态断链、构建被改动、旧复核等是否被可靠拦截。当前回归测试覆盖这一层。
2. **生成效果**：真实模型和人工流程能否产出正确声音、连续画面和忠实剧情。当前没有真实媒体样本或成绩。
3. **生产效率**：每合格分钟的总成本、返工次数、人工工时、端到端延迟与失败恢复。当前没有生产实测。

通过单元测试不等于达到行业顶尖。供应商展示也不能当作本仓库的成绩。

## 建立小型但有代表性的媒体测试集

覆盖多音姓氏、姓名连读、昵称、情绪喊名、同字不同音、长句、画外音；图像覆盖单人、双人、多人、手部、服装、道具、低光和跨场景；剧情覆盖线索、人物知识、时间顺序、关系变化和因果。

至少包括悬疑、日常/情感、动作和喜剧，保留独立开发集与盲测集，避免围绕唯一示例过拟合提示词。题材、角色数量、动作复杂度与时长分层报告，不只展示最成功的一条。

## 指标定义

- 姓名读音正确率：审核为正确的姓名出现次数 / 全部被审核姓名出现次数。词典中的姓名数量不是分母。
- 台词完整率：实际无漏词且无擅自改写的目标台词数 / 原剧本目标台词数。
- 剧情事实传达率：在实际成片中被正确传达的必需事实数 / 需表达事实总数。节拍 ID 覆盖率单独报告。
- 角色与道具缺陷率：有指定类别缺陷的审核镜头数 / 全部审核镜头数；同时记录缺陷严重度和持续时长。
- 每合格分钟成本：本轮全部生成及返工成本 / 最终合格分钟数。币种分别报告，人工工时另列；合格时长为零时记不可计算。
- 一次通过率、平均尝试次数与人工工时：保留所有尝试，不排除失败费用。

上述指标属于建议评测定义，未在当前 CLI 中自动计算。

生产侧已实现：成本台账的模拟实际/预留区分、按配置费率的估算、媒体实际时长与可选 ffprobe 规格探测、ASR 文本偏差辅助函数，以及自动/人工分栏质量报告。一次通过率、平均返工、人工一致性分数和读音错误数仍需真实记录；null 不是零缺陷。逐句 SRT 对齐不等于字级或口型对齐。

## 对照实验

为同一剧本、参考素材、画幅和时长预算比较三种条件：普通自由提示词；结构化提示词加共享设定；结构化流程加真实读音控制、参考图与人工门禁。不同条件改变了多个环节，整体对照用于衡量整条流程；若要归因于某条提示词，再做单变量消融实验。

事先规定各组尝试预算与停止规则，多次运行并保存所有输出。审核人尽量不知道实验条件，至少为部分样本安排独立复核；记录分歧与裁决。报告原始分母、样本量及不确定性，不用单个成功案例得出普遍结论。

实验记录模板见 `evals/run.template.json`。值为 null 表示未测，不能当作零成本或零缺陷。公开基准时附实际媒体、版本、请求、失败样本和人工复核依据；未取得发布许可的素材不进入公开测试集。
