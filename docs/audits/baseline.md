# M0：0.1 基线审计

日期：2026-10-24；起点提交：15c5e58。依据：全部 manju 源码、tests、README、docs、prompts、示例及 CI 配置。外部市场描述均未作为事实或代码常量。

## 模块与数据流

`cli → project.load_episode → validation → build → 冻结构建 → 外部手工制作 → review.gate`

project 展开共享设定并检查系列；validation 检查类型、ID、节拍、时间及状态链；build 编译提示词/配音/预览字幕/任务计划；io 提供严格 JSON、路径边界与摘要；providers 只有最小协议；review 检查人工记录和文件摘要。全部核心代码仅使用标准库。

## 基线验证

原有 38 项 unittest 通过。单集、系列、构建、复核模板与 hash 命令已在隔离目录运行；pending 的 gate 按设计退出 1。README 原先 hash 示例指向尚不存在的实际视频，已改为对已有快照求摘要以保证入门命令可直接运行。复核示例明确标注预期失败。tools/verify.py 将全部 README bash 命令隔离验证，避免覆盖已有 build。

已有测试覆盖输入类型、引用、状态、台词时序、构建确定性、防覆盖、DAG 无环、文件替换、旧源文件和共享设定变化、路径越界、CLI JSON。尚无执行恢复、成本、授权、媒体解码或交付测试。

## 五项能力差距

- 可执行：已有 DAG 计划；缺失执行器、任务状态、持久事件、恢复、幂等和取消；需新增执行侧契约。
- 可控成本：只有可空成本接口；缺失配置化价格、换算、估算、预算预留和对账；需使用 Decimal 和追加台账。
- 可追溯：已有剧本/模板/计划摘要；缺失实际生成请求、模型/参数/资产版本和最终媒体链；需新增资产库和运行记录。
- 可合规：文档提醒授权；缺失凭据、范围、期限和交付门禁；只实现记录检查，不作法律结论。
- 可交付：已有预览字幕；缺失实测时间轴、剪辑交接、整包摘要、客户报告和独立验证。

## 工具层与业务画像差距

- 文本、图像、视频、角色一致性、TTS、ASR、数字人口播、剪辑：均无真实适配器；仅图像/视频/TTS 有任务计划。新增逐层确定性 mock 与能力协商，保留旧 Provider 类型。
- 聚合入口：缺失；实现通用注册与逐镜头路由，不实现转售、订阅、多租户或平台发布。
- series_drama：具备系列设定与连续性检查；缺执行、实际成本与完整交付。
- ad_batch：缺商品、钩子变体、批处理隔离和血缘。
- client_service：缺修改轮次、报价参数、授权和验收单。
- shoppable_export：缺 SKU/链接/时间点元数据；仅实现文件导出，不接店铺 API。

## 技术债与风险

JSON 写入未保证跨平台 LF；状态文件写入无原子性；完整性摘要不是身份签名；canon_ref 可读取相对上级路径；媒体仅凭摘要核对，不能确定编码或内容。新增侧文件必须版本化、原子写入、采用可恢复日志，并使用构建内相对路径。既有 gate 行为保持兼容，商业交付使用更严格的扩展门禁。

结论：保留已验证的编辑层，将执行/预算/资产/交付层增量叠加。无真实授权与真实媒体时只可完成明确标记的 mock 演示，不能宣称已完成商业成片验证。
