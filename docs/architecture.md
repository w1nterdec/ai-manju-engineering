# 生产工作流架构

> 本页属于可选工程参考。个人实际制作先读[创作指南](creator-guide/README.md)；原有 mock 或接口契约不表示真实平台已接通。

## 已实现的数据流

共享设定/单集 → 编辑校验 → 冻结构建 → 确定性执行预览 → 事务预算预留 → 离线 mock 执行或外部手工制作 → 技术检查/人工记录 → 授权与画像门禁 → 独立可校验交付包。

- project/validation/build：保留 episode 0.1、原 CLI 和构建格式，唯一台词来源、状态链、摘要与不覆盖构建。
- adapters/planning：版本化能力、全层 mock、逐镜头回退路由、身份引用、适配器修订和依赖键。
- execution/costs：OS 单写入锁、SQLite 事务和追加事件、有界线程/重试、恢复、取消、幂等、四级预算和 Decimal 账本。
- assets：内容摘要 blob、不可变来源/批准版本、授权凭据与期限检查、实际任务血缘。
- media：标准库 PCM 实测，可选 ffprobe 严格限定本地协议；逐句字幕与 ASR 文本筛查函数，不做字级强制对齐或语音生成。
- delivery/business：通用剪辑交接、来源/授权/AI 元数据、生产与演示隔离、包摘要、四种配置画像和广告变体批次。

## 兼容与确定性

旧 gate 保持整集输入字节变化即失效。新执行器按任务参数、适配器修订与依赖键判断 stale，因此局部镜头改动只影响下游；二者范围不同。新增侧文件使用独立的 1.0 契约，未修改 episode 0.1，也没有需要破坏性迁移的旧数据。

构建与计划不写动态时间戳；执行事件写实际时间以便审计。已有构建和交付目录不可覆盖。状态与账本事务写入，JSON 侧文件原子替换。成功文件复用前核对摘要，真实供应商任务尚未接入，不会在恢复时盲目重提付费任务。

## 单机边界

一个运行目录只有一个执行器，任务受限并发。不同运行使用显式项目/集/镜头/批次标识共享预算账户；不要在多台机器通过网络共享 SQLite。配置、日志与输出禁止包含密钥，错误与 CLI 输出统一脱敏。核心全部标准库，真实适配器和可选依赖没有安装。

运行中取消停止新调度，在途任务完成后保存。显式模拟审核只适用于 mock，不是人工批准。更改媒体后旧复核记录失效。人工记录与摘要不提供真实身份认证或法律效力保证。

## 后续需要实际验证
