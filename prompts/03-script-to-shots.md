# 从剧本到分镜

输入：{已批准原剧本}、{角色设定}、{读音词典}、{初始状态}、{目标时长与工具能力}、{数据契约}。

将剧本划分为有序 beats；每个节拍列出必须传达的事实。台词逐字保留，并赋予稳定 line ID 和 speaker ID；不要把改写的台词伪装成原文。

分镜通过 beat_ids 和 line_id 引用原内容。每个镜头明确出场角色、地点时段、景别机位、一个清楚的主动作、表演、计划时长、对白时序与前后状态。画外音和旁白必须显式标记，不能为了通过出场检查随意添加人物。

检查：所有节拍覆盖，所有台词恰好一次，顺序保持，人物信息来源合理，状态链连续。多动作、复杂手部互动、关键文字与大幅镜头运动分别标为制作风险，提出拆镜或后期方案。缺少的事实标为缺失，禁止自行编造补齐。

若提供契约，输出严格符合该契约的 JSON，之后仍须运行检查器。无法在预算内合理表达时说明需要调整，不能靠不合理语速塞满时长。
