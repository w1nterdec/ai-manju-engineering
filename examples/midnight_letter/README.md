# 原创示例：午夜来信

这是一份 32 秒、4 镜头的原创制作计划，包含多音姓名、画外音、道具连续性和后期文字线索。示例尚未生成图像、音频或视频，不是效果演示或质量基准成绩。

建议先只做 S001：两张角色参考图 → 经确认的双人关键帧 → L001 配音试听 → 短视频 → 剪辑与字幕对齐。这个闭环验收后，再扩展到全部镜头。

- 单行舟：`shan4 xing2 zhou1`，用于测试多音姓氏与姓名连读。
- 乐知遥：`yue4 zhi1 yao2`，由本故事作者指定，不能推广为所有“乐”姓的唯一读法。
- S003 没有画面内角色，L003 为画外音；不应被误报为说话人漏画。
- 信封由桌面进入右手，此后始终封口；状态校验只检查计划，画面需人工验证。
- 日期、钟面等关键线索采用经过核对的后期合成，减少生成文字和指针错误。

`series/` 中的两集使用 `canon.json` 共享设定，演示跨集连续性；不要把第二集误当成已经制作的成片。
